Herleitung des Dispersionsverhältnis

Die Bewegungsgleichung der Masse $$m_n$$ ist gegeben durch:

$$m_n \ddot{u}_n = c (u_{n+1}-2 u_n + u_{n-1})$$

Aufgrund der Periodizität des Systems kann das Bloch-Theorem genutzt werden, um das Eigenwertproblem $$\omega(k)$$ anhand einer einzelnen Einheitszelle herzuleiten. Hierfür wird als Lösung der homogenen Differentialgleichung eine harmonische, ebene Welle angenommen.
Ansatz:

$$u(x_n,t)=u_n(t)=$$û$$(\omega)e^{-i\omega t}=A(k(\omega))e^{i(ka-\omega t)}$$

$$k$$ ist der Bloch-Wellenvektor und definiert mit: $$k=\frac{2\pi n}{Na}$$.
$$n$$ beschreibt die Nummerierung einer Einheitszelle und $$N$$ die gesamte Anzahl der Einheitszellen aus einem Auschnitt der periodischen Struktur, der mit dem Bloch Theorem die periodischen Randbedingungen erfüllt.
Mithilfe des Bloch-Theorems beschreibt û $$(\omega)$$ den Ausdruck der Phasenänderung von einer Einheitszelle zur nächsten benachbarten Einheitszelle.

û$$(\omega)=A(k(\omega))e^{ika}$$

Im Weiteren wird die Definition der dimensionslosen Wellenzahl $$\mu=\frac{2\pi}{Na}a$$ übernommen. Damit vereinfacht sich der Ansatz zu:

$$u_n(t)=A(k(\omega))e^{i(\mu n - \omega t)}$$

In die Differentialgleichung eingesetzt und unter Berücksichtigung der Beziehung $$2cos(x) = e^{ix}+e^{-ix}$$ ergibt sich:

$$Ae^{i(\mu n-\omega t)} [-\omega^2m + 2c(1-\cos{\mu})] = 0$$

Die nicht-triviale Lösung der Differentitalgleichung ergibt das Dispersionsverhältnis $$\omega(k)$$ der monoatomaren Masse-Feder-Kette:

$$\omega(k) = \sqrt{\frac{4c}{m}} | \frac{sin(ka)}{2}| = \sqrt{\frac{4c}{m}} | \frac{sin(\mu)}{2}|$$
